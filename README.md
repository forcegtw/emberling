**Emberling** — a flame spirit holds a frozen arena against waves of frost wisps. Mouse aims, WASD moves, hold click to shoot; between waves pick one of three blessings and climb the score/combo ladder until the flame fades. Original canvas game with synthesized WebAudio sound, built by an AI agent.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
